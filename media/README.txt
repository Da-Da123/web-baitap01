THU MUC CHUA FILE DA PHUONG TIEN CHO TRANG media.html
=====================================================

Trang media.html doc cac file sau (dat dung ten, dung thu muc nay):

  event-intro.mp4   - video gioi thieu su kien (dinh dang MP4/H.264)
  event-intro.webm  - ban WebM cua cung video (khong bat buoc)
  podcast.mp3       - file podcast phong van (dinh dang MP3)
  podcast.ogg       - ban OGG cua cung podcast (khong bat buoc)

Khi CHUA co cac file tren, the <video> va <audio> se tu dong
chuyen sang nguon du phong online (MDN shared-assets) da khai bao
san trong media.html, nen trang van bam play duoc binh thuong.

Khi da co file that, chi can copy vao thu muc nay - KHONG can sua
file media.html, vi trinh duyet luon uu tien <source> dau tien
doc duoc.
